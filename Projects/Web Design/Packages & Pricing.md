Suggested starting prices. Price on value, not hours. Take at least 50% of the build fee before starting.

| | Starter | **Growth (push this one)** | Pro |
|---|---|---|---|
| Build fee | $500 | $900 | $1,500 |
| Monthly | $150/mo | $300/mo | $500/mo |
| Site | 1 page | 1 page + motion upgrade | Up to 4 pages + motion |
| Edits | 2/month | Unlimited small | Unlimited small |
| Google Business Profile + review link + monthly report | | ✓ | ✓ |
| Ads management | | | ✓ (client pays ad spend) |

**Add-ons:** extra page $150 · seasonal promo page $100 · logo clean-up $75 · booking/order link $75.
**Math:** $6,000/mo goal ÷ $300 = 20 Growth clients.

## First 30 days after launch
1. Set up their Google Business Profile.
2. Send a one-tap review link (ask for 5 reviews).
3. Send the first monthly report.
4. Fix every small request same day.
