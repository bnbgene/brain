## What it is
BNB web design + ads for local (mostly Phoenix-area) businesses. Process:
1. Find a lead → it goes in the **Lead Desk**
2. Claude builds a **draft** sample site → you preview privately
3. You say "publish" → it goes live free on GitHub Pages
4. Send the link to the business owner
