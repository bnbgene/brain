# BNB packages + monthly client report

Suggested starting prices. Change them any time. Rule from the playbook: price on value, not hours.
If one new customer is worth $500 to a roofer, two extra calls a month pays for the whole plan.

## Packages (build fee + monthly)

Always take at least 50% of the build fee before starting. Monthly plans auto-bill.

| | Starter | Growth (push this one) | Pro |
|---|---|---|---|
| Build fee | $500 | $900 | $1,500 |
| Monthly | $150/mo | $300/mo | $500/mo |
| Site | 1-page site (like our samples) | 1-page site + motion upgrade | Up to 4 pages + motion upgrade |
| Hosting + security | ✓ | ✓ | ✓ |

| Google Business Profile set-up / clean-up | | ✓ | ✓ |
| One-tap review link for happy customers | | ✓ | ✓ |
| Monthly report (below) | | ✓ | ✓ |
| Seasonal promo banner or page | | 1 a quarter | 1 a month |
| Ads management (Google / Facebook) | | | ✓ (ad spend paid by client) |

**Add-ons:** extra page $150 · seasonal promo page $100 · logo clean-up $75 · online booking/order link set-up $75.

**Math:** monthly income goal ÷ $300 = Growth clients needed. Example: $6,000/mo ÷ $300 = 20 clients.

## First 30 days after launch (this is what keeps them)
1. Set up or clean up their Google Business Profile (photos, hours, services, website link).
2. Send them a one-tap review link and ask them to text it to 5 happy customers.
3. Send the first monthly report.
4. Fix every small request the same day.
