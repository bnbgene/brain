# Drafts

Sample sites waiting for the owner's OK. Nothing in here is published.

1. Claude builds `drafts/<slug>/concept.html` (+ `img/`) and shows the owner a private preview.
2. The owner asks for changes; Claude edits the draft and shows it again.
3. When the owner says publish, run `python3 tools/publish_sample.py <slug>`, commit, push once.
